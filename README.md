# 拾言 Shiyan · 一句话的留白

一个单文件的一言句子页：内置一言公共 API，双击换句，一键复制；可以写下此刻的心境与最近遇到的事，让 AI 结合你的处境解释句子、陪你想一想，也可以继续和它聊下去。句子历史、保存的对话和 API 设置都存在本机。

## 使用

直接双击 `index.html` 即可打开。也可以在当前目录启动一个本地静态服务：

```powershell
python -m http.server 8080
```

然后访问 <http://127.0.0.1:8080/>。

## 功能

- **一言句子**：内置 `v1.hitokoto.cn` 公共接口，免费、无需 API Key；接口失败时自动回退到本地句子。
- **换句**：点击「换一句」、按 `R`，或直接双击句子（双击会换句；若要复制局部文字，请按住鼠标拖选）。
- **复制**：点击「复制」复制句子、作者与出处；也可以用鼠标直接拖选文字，按 `Ctrl+C` 或右键复制。
- **心境与背景**：点「心境」选择此刻的情绪（可多选），写下最近遇到的事，字数不限。保存后句子下方会显示一条「此刻」摘要。
- **AI 解读**：没有心境时，先解释字面意思和关键意象；选了心境后，会少讲句子、多和你聊，像朋友聊天，而不是逐句赏析或上课。
- **继续对话**：初次解读后，可以在 AI 面板底部继续追问；上下文会带入下一轮。关闭面板再点「AI 解读」可以接着刚才的对话。
- **保存与历史**：点 AI 面板的「保存」会把对话存到本机；历史按钮里能看到刷过的句子和已保存的对话。保存过的对话重新打开后可以继续聊。
- **回到上一句与 AI 对话**：换过句子后，操作区下方会出现这个按钮；点击会回到上一句。保存过的对话会恢复，本次会话里未保存的对话也会作为草稿恢复。
- **刷新清空**：换一句会关闭当前 AI 面板；未保存的对话作为本次会话草稿保留在内存里，可通过「回到上一句与 AI 对话」找回。重新加载页面会从新的一句开始，未保存草稿消失；保存过的对话仍在历史里。
- **温柔模式**：当心境选了低落、焦虑、迷茫、疲惫、孤独、烦躁，或经历里出现明显的难受信号时，AI 会先理解你的感受，少讲句子，多陪你聊；语气放慢放软，不评判、不说教，也不否定这句话本身。
- **Markdown 渲染**：标题、加粗、引用、列表、代码、表格、链接等。
- **DeepSeek 深度思考**：使用 DeepSeek 接口时可单独开关；开启后先推理再落笔，思考过程可展开查看，不污染最终解读。
- **解读长度**：简短 / 适中 / 详尽 / 不限。前三档约 120 / 280 / 600 字；不限字数时不发送 `max_tokens`，让模型写到完整为止（实际仍受所选模型的最大输出限制）。
- **明暗主题**：右上角切换，自动记住选择。
- **移动端字体**：内置 Noto Serif SC 子集（约 1.3MB，`fonts/shiyan-serif.woff2`），从本站加载，不依赖 Google Fonts；手机也有衬线中文字体。字体遵循 SIL OFL，见 `fonts/OFL.txt`。
- **访问统计**：Cloudflare Pages Function + D1，GitHub Pages 和 Cloudflare Pages 共用一个计数；底部显示合计访问量。
- **用量与费用**：AI 面板底部显示本轮 tokens 和人民币费用；右上角图表按钮查看累计 tokens、累计费用、请求次数和最近记录。
- **设置**：填写 API 地址、模型、API Key 即可；内置 DeepSeek Flash / Pro 与 OpenAI 预设。

## 心境与隐私

- API 地址、模型、Key、心境、句子历史、保存的对话和用量都保存在本机浏览器的 `localStorage`；同一浏览器/同一域名下再次打开不需要重复填写。清空浏览器数据、换浏览器、换设备或换域名后不会自动带过去。
- 心境和事情只保存在本机浏览器的 `localStorage`，不会经过任何自建服务器。
- 点击「AI 解读」时，这部分内容会随提示词一起发送给你配置的模型接口。
- 修改心境后，如果 AI 解读面板正开着，会清空当前未保存的对话，避免旧内容和新心境混在一起；保存过的旧对话仍在历史里。
- 心境是可选背景。留空时，AI 只解读句子本身，不会虚构你的经历。
- 选了心境后，提示词会把重点从“解释句子”移到“陪你聊”：用短段落、口语化的朋友语气，不分析意象修辞、不列知识清单、不出现“首先/其次/综上所述”的讲课腔。即使仍提到句子，也只是轻轻带过。
- 情绪较差时，会进一步放慢：先接住感受，不急着解释句子；明确禁止说这句话“不好、不成立、太消极或太矫情”，也不强行给积极结论。
- AI 的回应仅供参考，不构成心理建议。如果文字里出现自伤或危机信号，提示词会让模型优先建议寻求身边信任的人或当地专业援助，而不是继续做文学分析。

## 访问统计说明

- 底部「访问 N 次」来自 `functions/api/visit.js`，数据存放在 Cloudflare D1。
- `https://blacklaegend.github.io/shiyan/` 和 `https://shiyan-9ee.pages.dev/` 调用同一个接口、同一个 `site=shiyan`，所以是合计访问量。
- 没有使用第三方统计脚本；D1 未绑定或接口不可用时显示 `—`。
- 上线前需要在 Cloudflare 创建 D1 数据库、执行 `counter-schema.sql`；`wrangler.toml` 已经声明了变量名为 `DB` 的 D1 绑定，详见 [DEPLOY.md](DEPLOY.md)。
- 当前只统计累计 PV，不保存每日历史；刷新页面会 +1。

## 历史与本地存储

- 每次刷到新句子都会自动写入本机历史，最多保留 60 条。
- 只有点过「保存」的 AI 对话才会持久化；未保存的对话换句或刷新页面后会消失。
- 历史面板可以点击任意一句恢复；「回到上一句与 AI 对话」按历史顺序回退；保存过的对话会连同心境一起恢复，本次会话的未保存草稿也能恢复，并在历史里标为「草稿」。
- 页面重新加载会开新的一句，不会自动恢复上次对话；从历史里点回保存过的那一条即可继续。
- GitHub Pages / Cloudflare Pages 只是静态托管，不提供服务器端数据库；这里全部用浏览器 `localStorage`，所以只对同一浏览器、同一域名有效。
- 换域名（比如 `github.io` 和 `pages.dev`）、换浏览器、无痕窗口、清空网站数据都会得到一套独立的本地存储。

## 用量与费用

- 请求会在支持的情况下带上 `stream_options.include_usage`，优先使用 API 返回的 `usage`。
- 如果接口没有返回 `usage`，会按中英文字符比例估算，并在记录里标「估算」。
- 本轮用量显示在 AI 面板底部；右上角图表按钮打开用量面板，查看累计 tokens、累计费用和最近 50 轮记录。
- DeepSeek 官方接口按官方价自动计算：区分高峰/空闲、缓存命中/未命中、输入/输出。高峰为北京时间工作日 9:00–12:00、14:00–18:00；法定节假日未单独识别，费用以平台账单为准。
- 自定义接口在用量面板里填写「输入 / 输出单价（元 / 百万 tokens）」后，从下一轮开始计费；此前记录不变。
- 用量记录只保存在本机 `localStorage`，可随时清空。记录里只保留句子片段，不保存心境和具体经历。
- 保存对话时，为了恢复后能继续聊，会连同心境背景和完整对话提示词一起保存在本机；不保存则只保留句子历史。

DeepSeek 官方参考价（元 / 百万 tokens，缓存命中 / 缓存未命中 / 输出）：

| 模型 | 空闲时段 | 高峰时段 |
| --- | --- | --- |
| Flash | 0.02 / 1 / 4 | 0.04 / 2 / 8 |
| Pro | 0.15 / 4.5 / 13.5 | 0.30 / 9 / 27 |

来源：[DeepSeek 模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。价格可能调整，请以官方页面和实际账单为准。

## AI 接口

设置中填写的地址兼容 OpenAI 的 `POST /chat/completions` 协议，例如：

| 服务 | API 地址 | 模型 |
| --- | --- | --- |
| DeepSeek Flash | `https://api.deepseek.com/chat/completions` | `deepseek-flash` |
| DeepSeek Pro | `https://api.deepseek.com/chat/completions` | `deepseek-v4-pro` |
| OpenAI | `https://api.openai.com/v1/chat/completions` | `gpt-4o-mini` |

### Flash 还是 Pro？

| | Flash | Pro |
| --- | --- | --- |
| 速度 | 更快 | 慢一些 |
| 成本 | 更低 | 更高 |
| 适合 | 日常刷句、普通心境、快速看看 | 复杂情绪、长背景、需要更细致的解释 |
| 深度思考 | 支持 | 支持 |

默认使用 **Flash**。在设置里选择 DeepSeek 官方接口后，可以直接点 Flash / Pro 卡片切换；模型卡片只在 `api.deepseek.com` 下显示。使用中转服务时，直接在「模型」输入框里填写对方提供的模型名即可。不确定时先用 Flash，遇到需要写得更深、更稳的长背景时再换 Pro。

- 使用 DeepSeek 官方接口，或模型名以 `deepseek` 开头时，会显示「深度思考」开关。开启后请求带 `thinking.type = enabled` 与 `reasoning_effort = high`；官方接口关闭时会显式传入 `disabled`。
- DeepSeek 的思考过程通过 `reasoning_content` 流式返回，显示在可折叠面板中，最终复制的内容不包含思考过程。
- 如果中转服务仍使用旧模型名，可以在设置里手动改成 `deepseek-chat`。
- 地址可以只填到 `/v1`，页面会自动补全 `/chat/completions`。
- API Key 只保存在当前浏览器的 `localStorage`，不会经过任何自建服务器；但它会直接发送给你填写的接口提供方。
- 仓库里没有任何 API Key。代码只包含输入框和 `localStorage` 读写；`.gitignore` 也排除了 `.env`、`*.key` 等常见密钥文件。不要把 Key 写进源码或提交。
- 如果浏览器控制台提示 CORS / 跨域错误，说明该接口不允许浏览器直连，需要改用支持 CORS 的接口或自建代理。
- 在公共电脑上使用后，建议到设置里清空 Key，并清空心境和用量记录。
